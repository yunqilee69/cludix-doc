# 部署与运维

本目录面向长期运行与团队使用：部署形态、数据库、开机自启、版本更新、通知与排障。

## 文档清单

| 文档 | 说明 |
| --- | --- |
| [部署形态](./部署形态) | 前台、后台守护、反向代理与多入口 |
| [数据库后端](./数据库后端) | SQLite / MySQL / PostgreSQL、初始化 SQL、多实例 |
| [开机自启](./开机自启) | systemd、LaunchAgent、Windows 注册表 |
| [版本更新](./版本更新) | CLI 与管理台一键更新、重启行为与失败处理 |
| [通知与告警](./通知与告警) | 配额阈值、Webhook/IM 渠道、站内通知中心 |
| [日志与排障](./日志与排障) | 日志位置、常见错误码、统计异常排查 |
| [安全与隐私](./安全与隐私) | 密钥存储、内容捕获、门户边界、远程库凭据 |

## 推荐顺序

1. 先确定 [部署形态](./部署形态)
2. 单机直接用 SQLite；多入口共享状态看 [数据库后端](./数据库后端)
3. 长期运行配置 [开机自启](./开机自启)
4. 打开 [通知与告警](./通知与告警)，再按 [日志与排障](./日志与排障) 建立日常巡检
