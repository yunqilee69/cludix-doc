# 技术分析入门

> 难度等级: ⭐⭐⭐⭐
> 前置知识: [什么是股票](../基础/什么是股票)、[估值方法初探](../进阶/估值方法初探)、[基本面分析入门](./基本面分析入门)

---

## 一句话理解

技术分析是"**用价格历史和成交量判断未来走势**"——它不关心公司好不好，只关心"资金在做什么"。

## 核心定义

技术分析是通过研究价格走势、成交量等市场数据，判断趋势和寻找买卖时机的方法。它回答"**何时买、何时卖**"，与基本面分析（回答"买什么"）互补。

## 生活类比

- **基本面分析** = 看食材新不新鲜、产地好不好（判断值不值）
- **技术分析** = 看锅里水开了没有、火候到没到（判断时机）

做菜两步都要：好食材 + 对火候。投资也一样：好公司 + 好时机。

## 详细拆解

### 1. 技术分析的三大假设（理论基础）

| 假设 | 含义 |
| --- | --- |
| 市场行为包容消化一切 | 所有信息（基本面/政策/情绪）都已反映在价格里 |
| 价格以趋势方式演变 | 趋势一旦形成，会持续一段时间 |
| 历史会重演 | 人性不变，同样的图形会反复出现 |

> 核心信念：**价格本身已经包含了一切**——这是技术分析的假设前提；实战中最好结合基本面一起看。

### 2. 核心工具一：K线（蜡烛图）

一根 K 线包含 4 个价格：**开盘、收盘、最高、最低**。

```
│     ← 上影线（最高价）
    ┌─┴─┐
    │   │  ← 实体（开盘~收盘）
    └─┬─┘
      │     ← 下影线（最低价）
```

- **红色（涨）**：收盘 > 开盘（中国习惯，涨=红）
- **绿色（跌）**：收盘 &lt; 开盘（跌=绿）
- 实体越长，力量越强

### 3. 核心工具二：均线（MA）

均线 = 过去 N 天的平均价格，代表"N 天内的平均成本"。

| 均线 | 含义 | 用途 |
| --- | --- | --- |
| 5 日 | 一周成本 | 短线 |
| 20 日 | 月成本 | 中线 |
| 60 日 | 季成本 | 中长线（季线） |
| 250 日 | 年成本 | 长线（年线/牛熊分界） |

**两个关键信号**：

- **金叉**：短期均线上穿长期均线 → 偏多信号（是提示，不是指令）
- **死叉**：短期均线下穿长期均线 → 偏空信号（是提示，不是指令）

### 4. 核心工具三：成交量

- **放量**：成交量放大，说明资金活跃
- **缩量**：成交量萎缩，说明观望
- **量价配合**：
  - 放量上涨 → 健康（资金推动）
  - 缩量上涨 → 可疑（没人跟进）
  - 放量下跌 → 危险（资金出逃）

> **量在价先**：成交量常用来验证趋势（放量突破更可信），但不总是领先价格。

### 5. 常用指标（了解即可）

| 指标 | 类型 | 用法 |
| --- | --- | --- |
| **MACD** | 趋势 | 金叉买入、死叉卖出 |
| **RSI** | 超买超卖 | >70 偏热、&lt;30 偏冷（强趋势中可能长期钝化，不等于买卖指令） |
| **KDJ** | 短线 | 金叉/死叉，短线交易 |

### 6. 趋势分析（核心中的核心）

| 趋势 | 特征 | 操作 |
| --- | --- | --- |
| 上涨 | 高点更高、低点更高 | 顺势做多 |
| 下跌 | 高点更低、低点更低 | 减仓/观望（A股普通账户做空需融券等高门槛工具） |
| 震荡 | 无方向 | 高抛低吸或不动 |

> **"趋势是你的朋友"**——顺势而为，不逆势。这是技术分析第一铁律。

### 7. 支撑位和阻力位

- **支撑位**：价格跌到某位置容易反弹（买方力量强）
- **阻力位**：价格涨到某位置容易回落（卖方力量强）
- 突破阻力 → 可能打开上涨空间
- 跌破支撑 → 可能开启下跌空间

### 8. 新手技术分析四步法

1. **看趋势**：上涨/下跌/震荡？（看均线排列）
2. **找支撑阻力**：当前价格在哪个区间？
3. **看信号**：金叉/死叉？超买/超卖？
4. **看量能**：放量还是缩量？配合吗？

> 顺序：趋势 > 位置 > 信号 > 量能。先看大方向，再看细节。

## 关键要点

- 技术分析 = 看价格和量，判断时机
- 三大假设：价格包容一切、趋势会持续、历史会重演
- 四大工具：K线、均线、成交量、指标
- 核心是"趋势"：顺势而为，不逆势
- 金叉偏多、死叉偏空（需结合趋势确认）；放量上涨健康、缩量可疑
- 新手四步：趋势→位置→信号→量能

## 易混淆概念对比

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 技术分析 | 基本面分析 | 看价格走势(何时买) vs 看公司本身(买什么) |
| 金叉 | 死叉 | 金叉=短期上穿(买)；死叉=短期下穿(卖) |
| 支撑位 | 阻力位 | 支撑=下方买盘强；阻力=上方卖盘强 |
| 放量 | 缩量 | 放量=资金活跃；缩量=观望 |
| 超买 | 超卖 | 超买=短期偏热；超卖=短期偏冷（不等于直接买卖） |

## 常见误区

- ❌ **误区1：技术分析能预测未来。** 错，它是概率，不是算命。
- ❌ **误区2：指标越多越好。** 错，指标会矛盾，2-3 个足够。
- ❌ **误区3：逆势操作能赚大钱。** 错，逆势=和趋势对着干，大概率亏。
- ❌ **误区4：K线形态百分百准。** 错，有"骗线"（主力制造假信号）。

## 延伸思考

技术分析的本质，是**通过价格和成交量，读取"资金的行为"**。价格涨，说明买方力量强；放量，说明资金活跃。它不关心"为什么"，只关心"是什么"。所以技术分析和基本面分析是互补的——基本面告诉你"买什么"，技术面告诉你"何时买"。两者结合，才是完整交易。
