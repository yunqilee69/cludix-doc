# 代码结构

仓库目录、模块职责与构建产物。

## 11. 技术栈与项目结构

| 组件 | 选型 | 理由 |
|---|---|---|
| 语言 | Go | 本细分领域 5 个独立项目（one-api/new-api/Bifrost/glide/BricksLLM）的共同验证 |
| HTTP | `net/http` + chi | 标准库够用，chi 提供轻量中间件 |
| ORM/存储 | GORM + modernc.org/sqlite | 纯 Go 无 CGO，交叉编译单二进制 |
| 热更新 | 写库后事件 → atomic.Pointer 快照替换 | 无锁读路径，进行中请求不受影响 |
| 协议适配 | `anthropic-sdk-go`（MIT，wire 类型+SSE 事件解析）+ `sashabaranov/go-openai`（Apache-2.0，OpenAI/Responses 类型） | 复用 SDK 类型而非手写结构体；映射表参考 one-api（MIT）；new-api（AGPL）仅作行为参考零拷贝 |
| 前端 | React 18 + Ant Design 5 + ECharts | 团队技术栈一致；产物 embed 进二进制 |
| 日志 | slog（结构化） | 标准库 |

```
OmniGate/
├── cmd/omnigate/main.go          # 启动引导：--db/--host/--port、建表、装配
├── internal/
│   ├── store/                     # SQLite/MySQL/Postgres 初始化、GORM 模型、迁移、方言收口
│   ├── config/                    # 启动层 YAML + app_config 读写 + 快照构建 + 热更新事件
│   ├── router/                    # 两级选择算法（模型→key）+ 会话亲和
│   ├── breaker/                   # 模型×密钥组合粒度的阶梯状态机 + 永久禁用
│   ├── proxy/                     # OpenAI 兼容转发、SSE 透传、重试转移、协议适配
│   ├── notify/                    # 配额告警扫描循环 + 通知渠道投递 + 站内通知渲染
│   ├── update/                    # 版本自检与一键自更新
│   ├── autostart/                 # 开机自启（systemd/launchd/注册表）
│   └── api/                       # 管理面 REST handlers + /v1 代理挂载 + 门户 REST
├── web/                           # React 源码（构建产物 embed）
├── docs/                          # 文档站源（同步到 cludix-doc/docs/projects/omnigate）
│   ├── index.md
│   ├── getting-started/           # 安装、五分钟上手、接入客户端
│   ├── guide/                     # 配置中心、路由、虚拟密钥、调用、门户
│   ├── operations/                # 部署、数据库、自启、更新、通知、排障
│   ├── design/                    # 架构、数据模型、熔断、协议转换
│   ├── development/               # 本地开发、代码结构、测试、发布、调试
│   ├── reference/                 # CLI、环境变量、配置、HTTP API、术语
│   └── images/
├── publish/cludix-doc/            # 文档站侧边栏源（CI 一起同步）
├── scripts/sync-docs.sh           # 本地同步/预览
└── go.mod
```
