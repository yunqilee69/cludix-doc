# 配置

OmniGate 把配置分成两层：启动层决定「进程怎么起来」，运行层决定「请求怎么转发」。

## 启动层

`config.yaml`，进程启动时读取。改完需要重启。

```yaml
server:
  host: 127.0.0.1   # 局域网访问改成 0.0.0.0
  port: 17777
admin:
  username: ""      # 登录账号：设置后 Web 管理台需登录
  password: ""      # 留空 = 本地免登录
```

对应环境变量：`SERVER_HOST`、`SERVER_PORT`、`ADMIN_USERNAME`、`ADMIN_PASSWORD`、`DATABASE_PATH`、`LOG_PATH`。

四级优先级：CLI flag > 环境变量 > `config.yaml` > 代码默认值。命令行覆盖见 [安装与启动](./安装与启动)。

`/v1` 网关调用现已使用虚拟密钥鉴权，在管理台「虚拟密钥」页面创建和管理，不再走启动层的 `api_key`。

## 运行层

管理界面改、SQLite 存、热替换。调熔断 / 捕获 / 限流对下一个请求立即生效，无需重启。

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 模型熔断 | 开启 | 30s → 1m → 3m 阶梯退避 |
| key 熔断 | 开启 | 401/403 立即禁用，429 短冷却 |
| 请求内容捕获 | 成功关闭 | 开关只控制成功请求；关闭时默认记转发失败 |
| 日志保留期 | 0（永久） | >0 时每小时自动清理 |
| Token / 费用定价 | 按模型 | 输入 / 输出 / 缓存命中三价，支持 `$` / `¥` |

启动层和运行层刻意分开：改 `config.yaml` 要重启；在 UI 调熔断 / 捕获 / 限流对下一个请求立即生效。运行层完整项见 [运行设置](./运行设置)。提供商代理、请求头模板、模型请求体覆盖不在 `config.yaml` 里，见 [配置中心](./配置中心)。
