# 国债逆回购

> 难度等级: ⭐
> 前置知识: 无

---

## 一句话理解

国债逆回购就是你把闲钱"借"给别人（对方用国债作抵押），到期拿回本金 + 利息——低风险地吃利息（信用风险极低，但不是绝对零风险）。

## 核心定义

国债逆回购，是指投资者把资金借出，借款方（通常是银行、券商等机构）以国债作为抵押品，到期后还本付息的一种短期融资交易。因为抵押品是国债，违约风险极低，被视作"准无风险"的现金管理工具。

## 生活类比

想象你的邻居急需用钱，但手里有一张政府发的"国债"（几乎不可能违约的借条）。他对你说：

- "我把国债押给你，你借我 10 万用 7 天，到期我还你 10 万 + 利息。"
- 你不怕他不还，因为国债押在你手里，到期不还你就把国债卖了抵债

这就是逆回购：**你出借资金、对方抵押国债、到期连本带息还你**。

## 详细拆解

### 1. 为什么叫"逆回购"

- **正回购**：机构用国债抵押借钱（他是借入方）
- **逆回购**：你借钱给机构、收国债作抵押（你是借出方）

一正一逆，就是同一笔交易的两个方向。散户做的是**逆回购**——把钱借出去。

### 2. 如何收益？收益怎么算？

**收益 = 利息，就这么简单。** 年化收益率实时波动，一般在 1%～5% 之间。

**收益计算公式：**

```
毛利息 = 本金 × 年化收益率 × 实际占款天数 / 365（净收益还要扣手续费）
```

**例子**：你有 10 万元，做 1 天期逆回购，年化 3%

```
利息 = 100000 × 3% × 1 / 365 ≈ 8.2 元
```

### 3. 什么时候收益高（关键技巧）

正常情况下收益率不高，但**特殊时点资金紧张，收益率会飙升**：

- **季末、年末、半年末**：银行考核，缺钱
- **长假前（春节、国庆）**：机构提前备钱
- 这些时候 1 天期逆回购年化有时能冲到 **10% 甚至更高**

### 4. 实操要点

| 项目 | 说明 |
| --- | --- |
| 期限 | 1天、2天、3天、7天、14天等 |
| 门槛 | 沪深均已统一为 1000 元面额起（及其整数倍） |
| 交易时间 | 交易日 9:30–15:30（比股票多半小时） |
| 费用 | 极低，10万元约收1元 |
| 风险 | 极低（国债抵押） |
| 特点 | 到期资金自动到账，无需操作 |

> 💡 **周四技巧**：周四做 1 天期逆回购，资金实际占用 3 天（周五、六、日），能吃 3 天利息；资金周五可用（可继续买股票）、下周一才能取出。这是老股民常用的"闲钱生息"小技巧。

---

## 关键要点

- 本质：把钱借出去、对方押国债，到期连本带息还你
- 收益：吃利息，年化 1%～5%，特殊时点可冲高
- 风险：极低（国债抵押）
- 适合：证券账户里的闲钱短期生息
- 记住公式：利息 = 本金 × 年化 × 天数 / 365

## 易混淆概念对比

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 国债逆回购 | 货币基金 | 都是低风险闲钱工具；逆回购利率随资金面波动更明显 |
| 国债逆回购 | 买国债 | 逆回购是"借出钱+国债抵押"；买国债是"持有国债吃利息" |
| 正回购 | 逆回购 | 正回购是借钱方；逆回购是出借方 |
| 逆回购 | 定期存款 | 逆回购更灵活、按天计息；定存期限固定 |

## 常见误区

- ❌ **误区1：逆回购是买国债。** 错，是"借钱给别人、对方押国债"，你并不持有国债。
- ❌ **误区2：逆回购收益很高。** 平时只有1%-2%，只有资金紧张时点才冲高。
- ❌ **误区3：逆回购风险很高。** 因有国债抵押，信用风险极低，常被视作准无风险利率；但操作失误、利率波动等小风险仍在，说"零风险"并不严谨。
- ❌ **误区4：随时都能做。** 只能在交易日、且资金要先在证券账户里。

## 延伸思考

国债逆回购是理解"利率""资金面"的绝佳窗口——为什么季末利率飙升？因为银行缺钱、资金供不应求，借钱成本就高。看懂逆回购利率的波动，其实是理解"钱的价格"（利率）最直观的方式，这也是理解《利率》的铺垫。
