# 货币与货币体系

> 难度等级: ⭐⭐
> 前置知识: 无（这是整个体系的起点）

---

## 一句话理解

货币是"交易的媒介"和"价值的标尺"；现代的钱，本质是国家信用背书的"记账符号"，本身并没有多少内在价值。

## 核心定义

传统定义里，货币是固定充当一般等价物的特殊商品，具有价值尺度、流通手段、支付手段、贮藏手段等职能。到了现代法币体系，货币由国家（央行）发行，靠国家信用背书，不再依赖商品价值。

## 生活类比

没有钱的世界，你是个养鸡的，想换别人家的大米：

- 你得先找到一个"既想要你的鸡、又正好有大米"的人——**双重巧合**，太难了
- 有了钱之后：把鸡卖成钱，再用钱买米——问题瞬间解决

货币就是那个**"所有人都愿意接受的中间物"**，它让交易从"以物易物"的笨拙，变成"用钱换万物"的高效。

## 详细拆解

### 1. 货币的演变史

| 阶段 | 形态 | 问题/特点 |
| --- | --- | --- |
| 物物交换 | 羊换米 | 需要"双重巧合"，效率极低 |
| 商品货币 | 贝壳、盐、牲畜 | 有了"一般等价物"，但不统一 |
| 金属货币 | 金、银、铜 | 有价值、易分割、易保存 |
| 纸币（信用货币） | 人民币、美元 | 本身无价值，靠国家信用背书 |
| 电子/数字货币 | 数字记账 | 连实体都不需要了 |

> 关键转折：从**金属货币**到**纸币**，钱从"本身有价值"变成了"靠信用"。现代的钱，只是一张印着数字、由国家担保的纸（或数字）。

### 2. 货币的三大核心职能

| 职能 | 含义 | 例子 |
| --- | --- | --- |
| 价值尺度 | 给商品标价 | 一件衣服标价 100 元 |
| 流通手段 | 充当交易媒介 | 用钱买衣服 |
| 贮藏手段 | 存钱保值 | 把钱存银行 |

> ⚠️ 贮藏手段在**通胀时代会失效**——存的钱会"变毛"，购买力缩水。这就是通胀对存钱者的伤害。

### 3. 现代货币体系：从金本位到法币

- **金本位**（历史上）：货币与黄金挂钩，可以兑换黄金，发行量受黄金储备限制
- **法币体系**（现代）：货币不与黄金挂钩，靠**国家信用**，央行可以调节发行量

> 现代法币的"锚"是**国家信用和央行纪律**，而不是黄金。好处是能灵活调控经济，坏处是如果央行失控超发，就会引发恶性通胀。

### 4. 钱从哪来？（多数人不知道的真相）

很多人以为"钱是印出来的"，其实现代货币主要靠**信贷创造**：

1. **央行发行基础货币**：真正"印"出来的那一小部分
2. **商业银行通过贷款创造货币**：你向银行贷款 100 万，这 100 万就"凭空"进入了经济体——这是现代货币的大头

> 所以现代货币的扩张，主要靠"**贷款**"这条管道。这也解释了为什么央行要控制利率——利率低，贷款多，货币就多，通胀压力就大。

### 5. 货币供应量：M0 / M1 / M2

| 指标 | 组成 | 含义 |
| --- | --- | --- |
| M0 | 流通中的现金 | 纸币 + 硬币 |
| M1 | M0 + 单位活期存款 + 个人活期存款 + 支付机构备付金 | 狭义货币，随时能花（2025 年起央行启用新口径） |
| M2 | M1 + 定期存款等 | 广义货币，衡量"钱总量" |

> 新闻常说"M2 增速 XX%"，就是在说"市场上的钱变多了多少"——钱多了，通胀压力就大。

### 6. 串联：货币是这一切的源头

把基础模块的四块知识连起来：

```
货币 → 超发/收紧
      ↓
  通胀/通缩
      ↓
  央行调利率
      ↓
  资产价格涨跌（风险收益、股票/债券/REITs）
```

**货币是源头，通胀是结果，利率是调节工具，风险收益是最终落脚点。** 这就是基础概念的完整传导链。

## 关键要点

- 货币 = 交易媒介 + 价值标尺，现代货币靠国家信用背书
- 演变：物物交换 → 商品货币 → 金属货币 → 纸币 → 电子货币
- 三大职能：价值尺度、流通手段、贮藏手段
- 现代是法币体系，不与黄金挂钩，靠央行纪律
- 钱主要靠"信贷创造"，不是印出来的
- M2 衡量"钱总量"，M2 增速快 → 通胀压力大
- 传导链：货币 → 通胀 → 利率 → 资产价格

## 易混淆概念对比

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 金属货币 | 纸币（信用货币） | 金属本身有价值；纸币靠信用背书 |
| 金本位 | 法币体系 | 金本位挂钩黄金；法币靠国家信用 |
| 基础货币 | 信用货币 | 基础货币是央行"印"的；信用货币是贷款创造的 |
| M1 | M2 | M1 是"随时能花"的钱；M2 是"钱总量" |

## 常见误区

- ❌ **误区1：钱就是印出来的纸。** 错，现代货币主要靠贷款创造，印刷只占很小部分。
- ❌ **误区2：钱本身有价值。** 错，现代纸币本身没价值，价值来自国家信用和人们的共识。
- ❌ **误区3：央行印钱一定通胀。** 不完全，如果经济也在增长、货币有对应商品，就不一定。
- ❌ **误区4：存钱是最安全的保值方式。** 错，通胀时代存钱会"变毛"，实际购买力缩水。

## 延伸思考

理解"货币靠信用"，你就能看懂很多事：为什么国家要维护货币信用？为什么恶性通胀会摧毁一个经济体？为什么比特币等加密货币被争论"是不是货币"？——核心都在于"大家是否普遍信任并接受它"。货币的本质，是**信任的制度化**。
