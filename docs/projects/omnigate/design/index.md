# 设计与架构

本目录收录内部实现与设计取舍。它们不影响日常使用，但能解释「为什么行为是这样」，也是排障和二次开发的参考。

| [总体架构](./总体架构) | 目标、非目标、请求链路、Web UI 页面清单 |
| [数据模型](./数据模型) | 实体关系与建表 DDL |
| [路由与负载均衡](./路由与负载均衡) | 逻辑模型 → 目标模型 → 密钥的选择算法 |

## 阅读建议

- 想知道请求怎么选模型、怎么重试：先看 [路由与负载均衡](./路由与负载均衡) 和 [请求生命周期与重试](./请求生命周期与重试)
- 想理解路由页上的健康状态：看 [熔断与恢复](./熔断与恢复)
- 想接原生协议或排查字段差异：看 [协议转换](./协议转换)
- 想理解统计和通知口径：看 [统计口径](./统计口径) 与 [门户权限与通知受众](./门户权限与通知受众)
