# 金融数据信息源

> 难度等级: ⭐
> 前置知识: [宏观经济与市场涨跌](./宏观经济与市场涨跌)

---

## 一句话理解

想拿第一手、不被人加工过的数据，直接去**官方渠道**（央行、统计局官网和官方公众号）；财经媒体适合"快速理解"，但要清楚它是"二手解读"。

## 核心定义

第一手数据源，指政策、数据由发布机构（央行、统计局、交易所等）直接发布的原始出处；二手信息则是媒体、平台对原始数据的转述和解读。

---

## 详细拆解

### 一、央行（中国人民银行）——货币政策第一手

| 渠道 | 入口 | 看什么 |
| --- | --- | --- |
| 央行官网 | [http://www.pbc.gov.cn](http://www.pbc.gov.cn) | 全部政策公告 |
| 央行公众号 | 微信搜"中国人民银行" | 政策速递（最省心） |
| 货币政策司栏目 | 官网子栏目 | LPR、MLF、准备金率 |

**央行发布的关键内容及节奏：**

| 内容 | 频率/时间 |
| --- | --- |
| LPR（贷款市场报价利率） | 每月 20 日左右 |
| MLF（中期借贷便利）操作 | 每月开展（时点不固定，以央行公告为准） |
| 金融统计数据（M2、社融） | 每月 10～15 日 |
| 货币政策执行报告 | 每季度 |
| 存款准备金率调整 | 不定期 |

### 二、国家统计局——经济数据第一手

| 数据 | 频率 |
| --- | --- |
| CPI / PPI | 每月 9 日左右 |
| GDP | 每季度 |
| PMI（官方制造业） | 每月最后一天 |
| 社零、工业增加值 | 每月中旬 |

> 官网：www.stats.gov.cn，也有官方公众号。

### 三、其他第一手渠道

| 渠道 | 看什么 |
| --- | --- |
| 中国货币网（chinamoney.com.cn） | Shibor、银行间市场利率 |
| 上交所 / 深交所官网 | 上市公司公告、交易数据 |
| 国家金融监督管理总局 | 银行/保险监管政策 |
| 中国外汇交易中心 | 人民币汇率 |

### 四、二手渠道（用于"快速理解"，不是"第一手"）

- **财联社、华尔街见闻**：快讯快，适合盯动态
- **东方财富、同花顺**：数据聚合 + 解读
- ⚠️ 关键：要能区分"**事实**"和"**解读**"——媒体标题常有倾向性

---

## 关键要点

- 第一手 = 官方（央行、统计局、交易所官网 + 官方公众号）
- 二手 = 财经媒体（快，但带解读、有倾向）
- 记住节奏：LPR 每月20日、CPI 每月9日、M2 每月10~15日、GDP 每季度
- 订阅官方公众号，是获取第一手信息最省心的方式

## 易混淆概念对比

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 第一手数据 | 二手解读 | 第一手是原始发布；二手是转述+观点 |
| 官方 PMI | 财新 PMI | 官方统计局（样本大而全、覆盖大企业）；财新（样本较小，市场认为偏中小企业/民营外向型） |
| LPR | MLF | LPR 是贷款报价利率；MLF 是央行投放资金利率 |

## 常见误区

- ❌ **误区1：财经媒体快讯 = 官方发布。** 应回官方渠道核实原文。
- ❌ **误区2：只看解读，不看原始数据。** 容易被媒体的倾向带节奏。
- ❌ **误区3：所有平台数据都一样准。** 二手平台可能有滞后或误差，关键数据以官方为准。

## 延伸思考

获取第一手数据，本质是在建立"**信息主权**"——不依赖别人的转述，自己看原始数字做判断。这对投资尤其重要：同样的数据，不同媒体能解读出完全相反的结论。先看事实，再看观点，顺序不能反。

## 延伸阅读

建议学习 **《估值方法初探》**，学会"怎么读这些数据"，把宏观数据落到具体资产的贵贱判断上。
