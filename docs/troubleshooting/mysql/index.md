# MySQL

本目录收录 MySQL 查询计划、索引和运行期报错的排查记录。

## 文档清单

| 文档 | 说明 |
| --- | --- |
| [重复前缀索引导致排序内存溢出](./重复前缀索引导致排序内存溢出) | 两条索引前缀相同，优化器选了不能排序的唯一索引，宽行 `ORDER BY ... LIMIT` 触发 `ERROR 1038`。 |

## 使用建议

1. 先用文档里的初始化 SQL 建出问题表。
2. 用一条消息很多的分组跑 `EXPLAIN` 和原查询，确认 `Using filesort` 与 `ERROR 1038`。
3. 再执行修复 SQL，确认计划变成按排序索引倒序扫描。
