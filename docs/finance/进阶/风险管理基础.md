# 风险管理基础

> 难度等级: ⭐⭐⭐
> 前置知识: [风险与收益的权衡](../基础/风险与收益的权衡)、[资产配置入门](./资产配置入门)

---

## 一句话理解

风险管理就是"**先保证自己不亏光、能活下来，再谈赚钱**"——投资的第一目标是活着，第二目标才是盈利。

## 核心定义

风险管理是通过识别、评估和控制投资中的风险，将潜在损失限制在可承受范围内的一系列方法和纪律。

## 生活类比

**开车系安全带**：安全带不能让你开得更快，但能让你出事故时活下来。风险管理就是投资的"安全带 + 刹车"——它不负责让你赚更多，只负责让你别死在半路上。

---

## 详细拆解

### 1. 为什么风险管理如此重要？（产生原因）

**核心是复利的数学——亏损和回本是不对称的：**

| 亏损 | 回本需要的涨幅 |
| --- | --- |
| -10% | +11% |
| -20% | +25% |
| -30% | +43% |
| -50% | **+100%** |
| -80% | **+400%** |

> 亏 50%，需要赚 100% 才能回本；亏 80%，需要赚 400%。**跌得越深，回本越难。**

所以投资界有句铁律：**"活下来，比赚得多重要。"** 控制回撤，远比追求高收益更关键。

### 2. 方法一：仓位管理

仓位 = 你投入的钱占总资金的比例。核心原则：**永远不要满仓，留有余地。**

- **不满仓**：留 10%～20% 现金，暴跌时才有子弹补仓
- **单一资产设上限**：单只股票/单一品种不超过总资产的 10%～20%
- **分批建仓**：不要一把梭，分几次买入，摊低成本

### 3. 方法二：止损

设定一个亏损上限（如 -10%），触发就卖出，避免深度套牢（止损线应因品种而异：个股可设固定比例，宽基指数/长期组合更适合仓位控制 + 再平衡）。

- 止损是"**承认错误**"，不是"失败"
- 目的是保护本金，把单次亏损控制在小范围
- 反例：死扛一只亏损 50% 的股票，回本需要赚 100%，可能好几年都回不来

### 4. 方法三：风险预算

提前规划"这笔投资最多亏多少"，而不是"能赚多少"。

- 例：总资金 10 万元，规定"单笔投资最多亏 5%"（5000 元）
- 用**闲钱**投资（3～5 年不用的钱）
- **绝不借钱、不加杠杆**——杠杆放大的是双向风险，可能爆仓归零

### 5. 方法四：分散实操

在资产配置的基础上，进一步分散：

| 维度 | 做法 | 降低的风险 |
| --- | --- | --- |
| 跨资产 | 股 + 债 + 现金 | 降低单一资产暴跌影响 |
| 跨行业 | 不押注单一行业 | 降低行业暴雷影响 |
| 跨市场 | A股 + 港股/美股（可选） | 降低单一市场暴露 |
| 跨标的 | 持有 10～20 只/宽基 ETF | 降低个股暴雷影响 |

> 记住：分散只能降低**非系统性风险**，躲不掉**系统性风险**（市场整体下跌）。

### 6. 新手风控清单（可直接执行）

1. ✅ 只用闲钱（3～5 年不用的钱）
2. ✅ 不借钱、不加杠杆
3. ✅ 单一股票/品种不超过总资产 10%～20%
4. ✅ 设止损线，纪律执行
5. ✅ 预留应急金（3～6 个月生活费）
6. ✅ 不满仓，留 10%～20% 现金

## 关键要点

- 第一目标：活下来，第二目标：赚钱
- 亏损与回本不对称：亏 50% 要赚 100% 才能回本
- 四大方法：仓位管理、止损、风险预算、分散
- 核心纪律：用闲钱、不杠杆、设止损、留子弹
- 控制回撤，比追求高收益更重要

## 易混淆概念对比

| 概念 A | 概念 B | 区别 |
| --- | --- | --- |
| 止损 | 割肉 | 止损是主动纪律；割肉是被迫恐慌卖出 |
| 仓位管理 | 满仓梭哈 | 仓位管理留余地；满仓梭哈不留退路 |
| 杠杆 | 现金 | 杠杆放大双向风险；现金是"安全垫" |
| 风险预算 | 收益预期 | 风险预算先想"最多亏多少"；收益预期只想"能赚多少" |

## 常见误区

- ❌ **误区1：止损就是亏钱=失败。** 错，止损是保护本金，避免小亏变巨亏。
- ❌ **误区2：满仓才能赚大钱。** 错，满仓一旦暴跌，没有子弹补仓，只能被动套牢。
- ❌ **误区3：加杠杆能放大收益。** 错，杠杆同时放大亏损，可能爆仓归零。
- ❌ **误区4：死扛总能回本。** 错，亏 50% 要涨 100% 才回本，可能多年都回不来，且可能永远回不来（退市）。

## 延伸思考

风险管理的本质，是对抗人性中的两个弱点：**贪婪**（满仓、加杠杆）和**侥幸**（死扛、不止损）。真正让你在市场上长期活下来的，不是预测能力，而是**纪律**——提前定好规则，到了就执行，不被情绪左右。这也是专业投资者和散户最本质的区别。
