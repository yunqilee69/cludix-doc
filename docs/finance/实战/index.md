# 实战

把知识落到实际操作：品种全景速查、技术分析、基本面分析、财报阅读，以及一个完整的基本面分析实战案例。

## 文档清单

| 文档 | 说明 |
| --- | --- |
| [投资品种全景对比](./投资品种全景对比) | 全品种收益/风险/流动性/门槛速查表 |
| [基本面分析入门](./基本面分析入门) | 财报三表、五步法，判断「好不好、能不能持续」 |
| [财报阅读与获取](./财报阅读与获取) | 年报速读六步、数据批量获取渠道 |
| [技术分析入门](./技术分析入门) | K线/均线/趋势，判断「何时买、何时卖」 |
| [江南高纤基本面分析实战](./江南高纤基本面分析实战) | 一个完整的基本面分析案例（教学用） |

## 使用建议

1. 先看「投资品种全景对比」建立全局观
2. 再学基本面 → 财报 → 技术分析，掌握分析工具
3. 最后用「江南高纤案例」走一遍完整流程，验证所学
