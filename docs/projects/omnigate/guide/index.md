# 使用指南

本目录按「配置 → 调用 → 自助服务」的顺序组织日常使用说明。

## 文档清单

| 文档 | 说明 |
| --- | --- |
| [配置中心](./配置中心) | 提供商、密钥、模型、请求头模板与请求体覆盖 |
| [路由](./路由) | 逻辑模型名、目标权重、兜底模型、健康状态 |
| [虚拟密钥](./虚拟密钥) | 调用凭证、小时请求数、并发、日/月限额、授权路由 |
| [调用与端点](./调用与端点) | OpenAI / Anthropic / Responses / Gemini 端点与 `provider/model` 直达 |
| [多模态与 MCP](./多模态与MCP) | Embedding、Rerank、生图、语音、视频与 MCP 工具网关 |
| [密钥门户](./密钥门户) | 使用者如何用密钥登录门户查看用量、模型与日志 |
| [对话测试页](./对话测试页) | 管理台内置 Playground，含 MCP 工具注入 |
| [运行设置](./运行设置) | 熔断、重试、流式、日志捕获、会话亲和、计费 |
| [启动层配置](./启动层配置) | `config.yaml` 与数据库连接 |

## 推荐顺序

1. 先按 [配置中心](./配置中心) 配好上游
2. 用 [路由](./路由) 把物理模型包装成客户端看到的逻辑名
3. 用 [虚拟密钥](./虚拟密钥) 发调用凭证
4. 按 [调用与端点](./调用与端点) 接入
5. 把凭证交给使用者后，他们在 [密钥门户](./密钥门户) 自助查看
