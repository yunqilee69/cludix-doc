# 平台支持

| 平台 | 状态 | 主要系统接口 |
| --- | --- | --- |
| macOS | 支持 | `lsof`、`ps`、`/bin/kill -TERM`、`proc_pidinfo` |
| Linux | 支持 | `ss`、`ps`、`/proc/<pid>/stat`、`/bin/kill -TERM` |
| Windows | 支持 | `netstat.exe`、`tasklist.exe`、`taskkill.exe`、Windows Process API |

实际可见范围取决于当前用户权限和操作系统安全策略。

- Linux 下 `ss -p` 可能隐藏其他用户进程的 PID / 进程名；缺少 `procfs` 或 `/proc` 受限时无法完成生命周期复核
- macOS 的系统隐私权限和 `lsof` 可见性会影响结果，受保护进程通常不可终止
- Windows 下若进程在两次系统查询之间退出，进程名可能暂时不可用；`tasklist` 不提供用户、可执行文件路径和完整命令行，因此这些字段可能显示为不可用
