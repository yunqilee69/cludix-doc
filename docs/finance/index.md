# 金融

从零开始的金融投资知识体系，按「基础 → 进阶 → 实战」三个阶段组织，覆盖货币、利率、股票、基金、债券、黄金、期货、估值、技术/基本面分析等主题。

## 板块结构

| 分类 | 内容 | 定位 |
| --- | --- | --- |
| [基础](./基础/) | 货币、利率、通胀、风险，以及股票/基金/债券/ETF/可转债/逆回购等品种入门 | 建立概念，理解「是什么」 |
| [进阶](./进阶/) | 基金分类、REITs、黄金、期货、资产配置、风险管理、估值、宏观、期权 | 深化理解，掌握「为什么」和「怎么用」 |
| [实战](./实战/) | 投资品种全景对比、技术分析、基本面分析、财报阅读、实战案例 | 把知识落到实际分析与决策 |

## 学习路线

1. 从「基础」的货币与利率开始，理解金融的底层逻辑
2. 进入「进阶」，掌握资产配置、估值、风险管理的方法论
3. 在「实战」中，用「技术面 + 基本面」完成一次完整的投资分析

> ⚠️ 本板块内容仅供学习参考，不构成任何投资建议。投资有风险，决策需谨慎。
