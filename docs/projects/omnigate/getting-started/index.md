# 快速开始

本目录帮助你在最短时间内把 OmniGate 跑起来，并从自己的应用里发出第一个请求。

## 文档清单

| 文档 | 说明 |
| --- | --- |
| [安装](./安装) | npm 安装、基本命令、数据布局、卸载与安装排障 |
| [五分钟上手](./五分钟上手) | 从空配置到第一个 `curl` 成功 |
| [接入客户端](./接入客户端) | OpenAI SDK、Anthropic 客户端与常见 AI 工具的接法 |

## 推荐顺序

1. 先看 [安装](./安装)，确认服务已经启动、管理台能打开
2. 跟着 [五分钟上手](./五分钟上手) 配好提供商、模型、路由和虚拟密钥
3. 按 [接入客户端](./接入客户端) 把实际应用接进来
