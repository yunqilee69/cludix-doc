# 安全与隐私

OmniGate 默认本地运行，但也会被放到局域网或反向代理后面。下面是你需要知道的边界。

## 两层凭证

| 凭证 | 保护对象 | 存储 |
| --- | --- | --- |
| 管理台账号 `admin.username` / `password` | `/manage` 与 `/api/*` | `config.yaml` |
| 虚拟密钥 `vk-...` | `/v1/*` 与 `/portal/api/*` | 数据库 |

两者互不替代：

- 管理台账号不能用于 `/v1` 调用
- 虚拟密钥不能进入管理台
- 管理台账号留空 = 本地免登录；只要服务暴露到本机之外，就应设置账号密码

## 上游密钥

- 明文存储在本地数据库（本地工具假设），界面默认脱敏
- 可显式点「显示」查看，API 需要 `reveal=1` 才返回明文
- 日志和统计只记录密钥名称/ID，不记录密钥值
- 门户与请求日志不返回上游密钥身份

## 请求内容捕获

元数据（路由、模型、token、延迟、状态码、费用）**始终记录**。请求/响应正文是另一回事：

- **成功请求捕获默认关闭**
- 关闭时仍记录真正转发失败的请求/响应，方便排查
- 路由全部实例无效、根本没发出上游请求时，无论开关都不记正文
- 打开后成功失败都写入 `content_log`，其中可能含敏感数据
- 白名单可以限制只捕获哪些逻辑路由或 `provider/model` 直达；空 = 全部

内容日志有自己的保留天数，`0` 表示不自动清理。清理动作见 [日志与排障](./日志与排障)。

## 门户边界

- 门户只挂虚拟密钥鉴权，不挂限流与配额中间件：超额时仍然能登录查看用量和配额
- 全站只读，没有创建、修改、删除入口
- 只能看到授权路由范围内的模型，以及发给自己的通知
- 标记已读/删除通知只在管理台提供

## 远程数据库凭据

- 连接串不写进 systemd unit、launchd plist 或 Windows 注册表
- 远程库实例注册开机自启时，必须把 `database.dsn` 放在 `config.yaml` 并通过 `--config` 给出
- 实例标识只使用 `driver://host:port/dbname`，不含用户名密码

## 更新安全

一键更新固定按「下载 → 校验 sha256 → 解压 → 临时文件 → rename」执行，校验条目缺失或哈希不符一律拒绝写入。

校验和只认官方源，不回退镜像。官方不可达时宁可更新失败。

## 部署建议

- 暴露到公网时放在 TLS 反向代理后面，并限制管理台来源 IP
- 给每个使用者单独发虚拟密钥，按需设置额度、并发与授权路由
- 定期检查通知中心里的 `model.disabled` 与 `quota.delivery_failed`
- 不要把 `config.yaml`、数据库文件和日志目录放进公开的静态目录
