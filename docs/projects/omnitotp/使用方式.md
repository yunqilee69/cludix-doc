# 使用方式

## 添加账号

点击右上角「添加账号」按钮，支持两种录入方式：

- **URI 输入**：粘贴从认证服务获取的 `otpauth://totp` URI
- **扫描二维码**：选择包含 TOTP 二维码的图片文件（PNG、JPG、JPEG、WEBP、GIF、BMP）

两种方式都可以同时设置 Issuer 名称和验证码显示策略。

**URI 格式**：

```text
otpauth://totp/[服务商]:[账号]?secret=[密钥]&issuer=[服务商]&algorithm=SHA1&digits=6&period=30
```

**参数说明**：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `secret` | Base32 编码的密钥（必需） | - |
| `issuer` | 服务提供商名称 | - |
| `algorithm` | HMAC 算法：SHA1 / SHA256 / SHA512 | SHA1 |
| `digits` | 密码位数：6 或 8 | 6 |
| `period` | 有效周期（秒） | 30 |

## 查看与复制验证码

添加成功后，账号卡片会实时显示验证码和剩余时间进度条，点击数字即可复制到剪贴板；若验证码处于隐藏状态，首次点击先显示，再次点击才复制。

## 编辑账号

点击卡片上的「编辑」按钮，可以修改 Issuer 名称和该账号的验证码显示策略（跟随全局设置 / 始终隐藏 / 始终显示）。全局开关「打开应用时默认隐藏验证码」位于右上角。

## 删除账号

点击卡片底部的「删除」按钮，再点「确认删除」移除账号（未确认时 4 秒后自动取消）。

## 批量导入

可直接编辑 [配置存储](./配置存储) 中的 `config.json` 批量添加账号，编辑后重启应用生效。
