# 环境变量

环境变量覆盖启动层配置，优先级低于 CLI flag、高于 `config.yaml`。

## 服务与鉴权

| 变量 | 对应配置 | 说明 |
| --- | --- | --- |
| `SERVER_HOST` | `server.host` | 监听地址 |
| `SERVER_PORT` | `server.port` | 监听端口 |
| `ADMIN_USERNAME` | `admin.username` | 管理台登录用户名 |
| `ADMIN_PASSWORD` | `admin.password` | 管理台登录密码 |
| `LOG_PATH` | `log.path` | 日志路径，支持 `stdout` / `stderr` / `off` |

## 数据库

| 变量 | 对应配置 | 说明 |
| --- | --- | --- |
| `DATABASE_DRIVER` | `database.driver` | `sqlite` / `mysql` / `postgres` |
| `DATABASE_PATH` | `database.path` | SQLite 数据库文件路径 |
| `DATABASE_DSN` | `database.dsn` | MySQL / PostgreSQL 连接串 |
| `DATABASE_INIT_SQL` | `database.init_sql` | 初始化 SQL 文件列表，PATH 同款分隔符 |

连接池参数（`max_open_conns`、`max_idle_conns`、`conn_max_lifetime_s`）没有环境变量覆盖，写在 `config.yaml` 里。

## 版本更新

与 npm postinstall 同名同义，便于内网自建镜像：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `OMNIGATE_UPDATE_API_BASE` | `https://api.github.com` | GitHub API 基址 |
| `OMNIGATE_UPDATE_GITHUB_BASE` | `https://github.com` | GitHub 网页基址 |
| `OMNIGATE_UPDATE_CDN_BASE` | `https://cdn.yunke.icu/omnigate` | R2 镜像基址 |
| `OMNIGATE_USE_CDN` | 未设置 | `1` 时归档优先走 CDN |
| `OMNIGATE_GH_PROXY` | 未设置 | GitHub 加速前缀，只作用于归档地址 |

## npm 安装

| 变量 | 说明 |
| --- | --- |
| `OMNIGATE_USE_CDN` | `1` 时安装期优先从 CDN 下载 |
| `OMNIGATE_GH_PROXY` | GitHub 加速前缀 |
| `OMNIGATE_DOWNLOAD_TIMEOUT` | 下载超时秒数，默认 30 |
| `OMNIGATE_SKIP_POSTINSTALL` | `1` 时跳过 postinstall，手动放置二进制 |

## 自启托管

| 变量 | 说明 |
| --- | --- |
| `OMNIGATE_SUPERVISED` | 由 systemd / launchd 注入，标记当前进程受管理器托管；用户无需手动设置 |
